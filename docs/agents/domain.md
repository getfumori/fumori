# Domain Docs

This repository uses a single-context domain documentation layout.

## Before exploring

Read:

- `CONTEXT.md` at the repository root
- Relevant ADRs under `docs/adr/`

If either location does not exist, proceed silently. Domain documentation is
created or extended only when terms or decisions are resolved.

## Vocabulary

Use terms as defined in `CONTEXT.md`. Avoid drifting to synonyms that the
glossary explicitly rejects. If a needed concept is absent, reconsider the
terminology or record the gap for domain modeling.

## ADR conflicts

Surface any contradiction with an existing ADR explicitly instead of silently
overriding it.
