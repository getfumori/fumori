# Fumori

Fumori is a private, self-hosted knowledge system: a forest grown from your
words.

The product is designed around durable Markdown notes, explicit links and
relationships, isolated Vaults, and AI that can read and map authorized
knowledge without silently rewriting Human Notes.

## Repository status

This repository currently contains the implementation-project bootstrap and
the accepted research baseline. Product code has not started.

The first shippable scope and responsive interaction design are intentionally
deferred to the next product-design session. They must be settled before an
implementation spec or backlog is created.
